# Day 3 - CSS and JavaScript Fundamentals

## Overview

This repository contains the practical exercises completed during Day 3 of the Java Full Stack Development Placement Training.

The focus of today's session was learning how to style web pages using CSS and add interactivity using JavaScript.

---

## Programs Included

### 1. CSS Selectors Demonstration

A webpage designed to demonstrate different types of CSS selectors and their effects on HTML elements.

#### Concepts Practiced

* Element Selector
* ID Selector
* Class Selector
* Universal Selector
* Text Styling
* Background Colors
* Font Customization

#### Key Learning

Understanding how CSS targets and styles specific HTML elements.

---

### 2. Classic HTML Page with Inline CSS

A simple webpage combining HTML elements with inline CSS styling.

#### Features

* Colored headings
* Styled table
* Marquee text
* Header and Footer sections
* Background customization

#### Concepts Practiced

* Inline CSS
* Text Styling
* Table Formatting
* Basic Page Layout

---

### 3. Styled Registration Form

A registration page designed using internal CSS styling.

#### Features

* Header and Footer
* Styled Input Fields
* Labels and Text Areas
* Form Design
* User Information Collection

#### Concepts Practiced

* Form Elements
* CSS Styling
* Border Radius
* Input Customization
* Layout Design

#### Key Learning

Creating user-friendly forms with better visual presentation.

---

### 4. CSS Grid Layout

A simple image gallery built using CSS Grid.

#### Features

* Two-column responsive layout
* Grid container
* Image positioning
* Box styling

#### Concepts Practiced

* CSS Grid
* Grid Template Columns
* Layout Management
* Responsive Design Basics

#### Key Learning

Understanding modern webpage layout techniques using CSS Grid.

---

### 5. JavaScript Events and Operations

A webpage demonstrating JavaScript event handling and arithmetic operations.

#### Features

* Single Click Event
* Double Click Event
* Mouse Hover Event
* Right Click Event
* Addition Operation
* Subtraction Operation
* Multiplication Operation
* Division Operation
* Alert Messages

#### Concepts Practiced

* JavaScript Functions
* Event Handling
* User Interaction
* Variables
* Arithmetic Operations
* Browser Alerts

#### Key Learning

Introduction to JavaScript and how it adds interactivity to web pages.

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Web Browser

---

## Learning Outcomes

After completing today's exercises, the following concepts were understood:

* Applying styles using CSS selectors
* Difference between ID, Class, Element, and Universal selectors
* Designing forms with CSS
* Building layouts using CSS Grid
* Handling browser events with JavaScript
* Creating interactive webpages
* Writing basic JavaScript functions
